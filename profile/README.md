# Open Autonomous Systems Alliance

An open community building open-source autonomous systems: drones, ground robots, boats, subs, mesh radios and sensors, on one secure, shared platform.

**Status:** founding. We're recruiting the first members and starting the first projects.

## Start here

- 🌳 **[Tech tree](https://joinoasa.org/techtree/)**: every technology we plan to build, what each needs and what it unlocks. Green nodes are ready to start.
- 🛠️ **[techtree](https://github.com/joinoasa/techtree)**: one issue per node. Pick one up, ask questions, see who's working on what.
- 💡 **[Discussions](https://github.com/orgs/joinoasa/discussions)**: ideas, questions and proposals.
- 🌐 **[website](https://github.com/joinoasa/website)**: the code behind joinoasa.org. Fixes welcome.
- ✋ **[Apply to join](https://joinoasa.org/join/)**: membership is free. Apply or be invited.

## How we work

- **Open by default:** designs, code and docs are published openly.
- **Secure by default:** every link is encrypted.
- **Build on what exists:** PX4, ArduPilot, ROS 2, MAVLink, TAK and Meshtastic come first. We write new standards only where there's a gap.
- **Short, clear docs:** if a question is answered twice, it becomes a doc.
