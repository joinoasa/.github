# Contributing to OASA

Thanks for your interest. Here's how to help.

## Anyone can

- **Comment and suggest** on any issue or discussion.
- **Post ideas** in [Discussions](https://github.com/orgs/joinoasa/discussions) using the Idea template.
- **Fix the website and docs** by opening a pull request on [website](https://github.com/joinoasa/website).
- **Report a security problem** privately (see [SECURITY.md](SECURITY.md)).

## Members can

- **Pick up a tech tree node.** Find a ready node on the [tech tree](https://joinoasa.org/techtree/) or among the [techtree issues](https://github.com/joinoasa/techtree/issues?q=is%3Aopen+label%3Astatus%3Aavailable), then comment that you'd like to start it. A lead will assign it to you.
- **Start a project.** Personal projects just get registered. Community projects need a lead and a one-page charter. See [projects](https://joinoasa.org/docs/projects/).

Not a member yet? [Apply](https://joinoasa.org/join/). Membership is free.

## Pull requests

- Keep each pull request small and focused on one change.
- Say what changed and why. Add screenshots for anything visual.
- Turn on two-factor authentication on your GitHub account.
- Work is licensed under the project's license. By default that's Apache 2.0 for software, CERN-OHL for hardware and CC BY-SA for docs ([details](https://joinoasa.org/docs/licensing/)). Only contribute work that's yours to give, and check any employer agreements first.

## Style

Short, clear, not wordy. Using AI to help write is fine. Then cut anything wordy.
